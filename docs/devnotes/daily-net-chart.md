# Daily Net Chart Guidelines

**Purpose.** The Daily Net chart in `DailyNetChart.vue` tracks three interrelated metrics for each date: gross income, gross expenses, and the net delta. It lives on the dashboard and drives `FinancialSummary` data via emitted events.

**Visual rules.**

- **Stacked bars.** Expenses render as the red column extending downward from 0, income as the green column building upward, and refunds as a separate teal segment above income. All share one stack (`net-stack`). Bars are **period buckets** (day, Monday week, month, quarter) chosen from the preset/range; YTD and 1Y are monthly, never one bar per day (TP-20261019-001).
- **Net indicator.** Net is not a bar. `netDashPlugin` draws the signed economic-net value as a yellow dash (with a dark under-stroke) as wide as each bar, in front of the bars. Net = income + expenses + refunds.
- **Prior-period overlay.** The comparison overlay line uses a light grey/white stroke (`--color-text-light` or `#f8fafc`) to stay visible against the dark card without clashing with the yellow net line.
- **Trendline colors.** Moving-average lines rely on purple (`--color-accent-purple`, 30-day) and blue (`--color-accent-blue`, 7-day) so they stay distinct from the cyan refund segment; they exist only on daily bars, while the flat average income/expense lines match the green/red bar colors and render with a subtle dashed stroke so they stay visually tied to the daily stacks. These trendlines should remain thin, transparent-filled strokes with no visible points.
- **Scaling.** The y-axis is configured with `stacked: true` so the bars grow from zero in appropriate directions. Do not convert expenses to positive values or change the axis stacking without a clear reason.
- **Density tuning.** Bar width (`maxBarThickness`) and tick count are derived from the number of buckets and viewport width; axis ticks use compact currency and honest per-bucket labels (year added when a range spans years).
- **Persistent detail zone.** The chart uses a fixed detail zone rendered above the canvas and below the overlay legend, replacing floating tooltip/pointer behavior. This placement keeps values visible during hover and click interactions while avoiding overlap with bars, the net dash, and comparison/trend lines. The information hierarchy is stable: active bucket dates first, signed **Economic Net** as the primary figure, then Income, Expenses, Refunds, and Transactions, followed by comparison content (`This Day Last Month`, `vs prior` delta, and percent change when the prior value is non-zero). Divide-by-zero comparisons intentionally omit percent text to avoid noisy output. The detail zone is driven by the selected bucket key; hover, click and keyboard update it, pointer exit preserves it, and a period change resets it to the latest active bucket.
- **Legend.** The default Chart.js legend remains hidden. The component renders an always-visible base legend (Income, Expenses, Refunds when present, Economic net dash) plus chips for active overlays (`Avg Income`, comparison, `30-Day Avg`, `7-Day Avg`) in draw order.
- **Drilldown.** Weekly/monthly/quarterly bars drill into their days in-chart (Back control + breadcrumb; global dates untouched). Daily bars emit `bar-click` for the existing day modal. A keyboard path and a disclosed bucket table cover non-pointer use. Hover chips were removed; the details card is the single readout.
- **Container chrome contract.** Chart wrappers, detail zones, overlay popovers, and overlay popovers use the shared angular chart container tokens (`--chart-shell-*`) so corners, borders, and panel depth remain aligned with dashboard/table controls. This contract updates chrome only and does not change plot geometry, value hierarchy, or overlay ordering.

**Why it matters.** The combination of stacked income/expense bars with a front-facing net line supports the “what you earned vs what you spent vs what you kept” story we want everywhere, while the persistent detail zone keeps metric context visible without covering bars or lines.

**Shared accent baseline.** The Daily Net control styling (timeframe toggle, overlay options trigger, and linked accent utilities such as `.gradient-toggle-btn`) is now the shared dashboard accent baseline, not a chart-local exception. When adding or updating interactive dashboard controls, start from the Daily Net accent tokens (`--accent-primary`, `--accent-primary-strong`, `--accent-primary-contrast`, `--accent-surface`) and only diverge with explicit product/design direction.

**Change control.** This section defines the baseline. Any future tweaks to stacking behavior, detail-zone content hierarchy, colors, or legend visibility should be made only with explicit product or design direction so the chart remains consistent with the documented intent.
