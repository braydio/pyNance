# Completed Task Packets

Only packets with **Status: Complete** belong in this directory.

Do not execute work from packets here unless a new active packet explicitly reopens or extends that work.

When moving a packet here, update:

- the packet's Status and Last updated fields;
- `docs/task-packets/INDEX.md`;
- `docs/task-packets/TRACKER.md`.

The immutable Packet ID and filename remain unchanged.
