# Archived Task Packets

Only packets with **Status: Superseded** or **Status: Cancelled** belong in this directory.

Archived packets are historical context, not executable instructions. If superseded, the packet or tracker should identify the replacement Packet ID when one exists.

When moving a packet here, update:

- the packet's Status and Last updated fields;
- `docs/task-packets/INDEX.md`;
- `docs/task-packets/TRACKER.md`.

The immutable Packet ID and filename remain unchanged.
